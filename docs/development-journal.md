## 四、踩坑与心得(完整记录见《回顾与感想》)

### 最贵的坑:Windows 中文编码

Git Bash 下 curl 命令行中文按 GBK 发送 → 服务端 UTF-8 关键词匹配全部失败。解决:请求体写 UTF-8 文件 + `curl -d @文件`;Python 脚本用 `\uXXXX` 转义 + `sys.stdout.reconfigure(encoding="utf-8")`。

### 最隐蔽的坑:同类型参数互换

`ToggleLike(userId, postId)` 写成 `ToggleLike(postId, userId)`,编译器不报错,只有全流程 curl + 查表才能现形。

### 最有价值的认知:Agent 没有魔法

Agent = 意图判断(关键词规则)+ 工具调用(接口抽象)+ 状态记忆(Redis 持久化)。写操作必须二次确认:先存草稿、用户带 `confirm_draft_id` 确认后才落库,确认即销毁防重复——这是 AI 直接写库的安全边界。
