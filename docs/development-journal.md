### 0.3 第 4 天并发:最密集的追问期(08-14 ~ 08-16)

练习件:Channel、gotoutine、Reflect、context、works/4(并发计数)、works/5(并发 map)、works/6(反射→context 点外卖)。

| 我的问题 ----------------------| 得到的答案(认知跃迁) -----------------------------------------------------------|
|--------------------------------|---------------------------------------------------------------------------------|
| 「为什么全是负数还固定 -10000?」 | 锁竞争 = 抛硬币:谁先抢到锁谁先跑完整个循环;跑 10 次结果是 +10000×6 / -10000×4,调度说了算 |
| 「锁写循环里死锁、写外面读到 0?」 | Mutex **不可重入** + 循环内 defer = 第二次 Lock 永远等不到;锁外读 = 绕过门偷看,锁管不着 |
| 「加锁是 0000,sync.Map 是 1234?」 | 锁只保证互斥不保证顺序 |
| 「value 拿值、elem 改值?」 | 反射:`ValueOf(ptr)` 包装指针,`.Elem()` 解引用到真实变量,`CanSet()` 只有指针+Elem 才为 true |
| 「context 那个 for 循环干嘛的?」 | for+select+default = 非阻塞轮询,保持 worker 存活;裸 select = 一次性等待 |
| 「为什么加 time.Sleep 才打印收到取消?」 | **main 返回 = 杀进程**;收尾用 wg.Wait(),不赌 sleep 运气 |

### 0.4 第 5 天网络:把"两台机器怎么对话"讲成一个故事(08-16 夜 ~ 08-17)

认知主线(按抽象层递进):**TCP(裸字节流)→ HTTP(请求/响应)→ RPC(函数调用)→ WebSocket(双向长连接)**。

| 我的问题 | 得到的答案(认知跃迁) |
|---|---|
| 「handler 是函数???」 | 回调函数:你定义,服务器替你调用,自动填好 (res, req) |
| 「res.Header().Set 而不是 res.Set?」 | ResponseWriter 接口只有 3 个方法(Write/WriteHeader/Header);Header 是独立的"信封"对象,Set/Add/Get 是它的方法 |
| 「net/http 直接导入 net 不行吗?」 | import 路径 = 磁盘目录路径;**net 和 net/http 是两个独立包**,没有包含关系 |
| 「fmt.Fprintf 为什么要传 w?」 | 格式化是 fmt 的活,写给谁(w)是调用者的事;w 只是"能接字节的东西"(io.Writer) |
| 「POST 我用不了?」 | 浏览器地址栏只会发 GET;真实 POST 是网页代码发的;测试入口 = curl / Apifox / HTML 表单 |
| 「为什么只有 map 需要 make?」 | Go 零值可用:int 零值 0、Mutex 零值=未锁、**map 零值 nil 不能写** |
| 「lock.Lock 是什么东西?」 | 门+门栓:Lock=进门插栓,Unlock=出门拔栓;拿不到锁就阻塞排队,不是报错 |
